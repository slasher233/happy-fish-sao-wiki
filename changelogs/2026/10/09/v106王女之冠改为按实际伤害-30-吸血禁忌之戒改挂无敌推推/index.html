    v1.06：王女之冠改为按实际伤害 30% 吸血、禁忌之戒改挂「无敌推推」

    作者​实测​v1.05​的​两件​装备​后​发现​两处实际​无效的​效果​，​v1.06​只​做​这​两件事​：禁忌​之戒的主动技（自建 Y03A，ANcl/Channel 系）点击没有反应，按作者要求不重​做，直接把乌贼娘娃娃那套现成的主动技 Y207「无敌推推」挂上去；王女​之冠的原生吸血 Y041 不生效，于是套用真红白之圣灵剑的吸血模板，但把「基于体力值」换成基于​实际​造成​伤害​的​30%。

    一​、​禁忌​之戒​：​为什么​点​了​没​反应¶

    v1.05 的主动技「瞬间加速」是自建技能 Y03A，取自母图 ANcl（Channel 系）。Channel 类技能本身不产生效果，必须在触发器里监听「单位开始施法」才会动 —— 而母图里没有任何按 Y03A 的事件，​所以​点​下去​只是​耗蓝​/​进​冷却​，​看不到​位移​。

    乌贼​娘​娃娃​的​主动​技则​是​母图​自带​脚本​按技能​id 处理的（note_log/extract/war3map.j:100761）：

    function P2E_GreavesActive takes nothing returns nothing
    local unit P2E_u=GetTriggerUnit()
    if GetSpellAbilityId()=='Y207' then
        call SetUnitInvulnerable(P2E_u,true)
        call PH_Byh(P2E_u,GetUnitFacing(P2E_u),700.,.25,...)   // 向面向方向冲 700 码
        call TriggerSleepAction(1.)
        call SetUnitInvulnerable(P2E_u,false)
    endif
    set P2E_u=null
endfunction

    它注册在 P2E_Init 里（TriggerRegisterAnyUnitEventBJ(P2E_spell,EVENT_PLAYER_UNIT_SPELL_EFFECT) + TriggerAddAction），与​物品​无关。所以 v1.06 只要把 Y207 写进禁忌之戒的技能表即可：

    项 v1.05 v1.06
    iabi Y02B,Y02C,Y02D,Y039,Y03A Y207,Y02B,Y02C,Y02D,Y039
    icid Y03A Y207
    介绍​栏 能力​:​瞬间​加速​(​向​面向​方向​快速​位移​,​CD12​秒​) 能力​:​无敌​推推​(​向​面向​方向​冲刺​700​码​,​期间​无敌​,​CD15​秒​)
    计划里的 Y03A 定义 新建（ANcl 系） 整块​删除（​弃用​，​w3a​对象​2194​→​2193​）

    冲刺​700​码​+​期间​无敌​+​CD​15​秒​，​全部​由母​图​既有​触发器​完成​，​本版没有​为​它​写​一行​脚本。

    二​、​王女​之冠​：​为什么​原生​吸血​没​生效¶

    v1.05 按拍板把「沐浴鲜血」交给原生生命偷取：新建 Y041（克隆母图 AIav），写 Uav1=0.3、atar=self。实测不生效的原因是 Y041 没有 abuf（没有承载 buff）—​—​母图​同类​原生​吸血​都​带​buff​字​段​，​缺​buff​的​光环​不会​产生​偷取​效果​。

    三​、​v1.06​的​做法​：​套用​真​红白​的​模板​，​但​按​实际​伤害​结算¶

    真红白之圣灵剑（I06O）的「夏娃之力」是母图自带触发器实现的（war3map.j:29951 function o74）：

    set P2_Heal=I2R(GetHeroStatBJ(2,P2_Wielder,true))*2.   // 真红白：体力值 × 2（固定值）
call HF22LS_Heal(P2_Wielder,P2_Heal)                    // 同一个回血入口

    v1.06 把 Y041 从王女之冠的技能表摘除（技能对象保留在 war3map.w3a 库里，只是不再挂载），改为脚本实现，套用同一个回血入口 HF22LS_Heal（war3map.j:5684），但把「体力值」换成伤害​事件​里​的​最终​伤害：

    // note_log/work/hfx6_module.j —— HFX5_DmgAct 攻击方 I0Q9 分支
call HF22LS_Heal(src,dmg*0.30)   // dmg = GetEventDamage()，即该次实际造成伤害的 30%

    伤害总线沿用母图的 wY(trigger)（单位进世界时自动挂 EVENT_UNIT_DAMAGED），所以普攻与技能伤害都会结算吸血；HF22LS_Heal 内部是 SetWidgetLife，不产生伤害事件，不会递归。

    项 v1.05 v1.06
    I0Q9.iabi …,Y032,Y041,Y042,Y043 …,Y032,Y042,Y043（去掉 Y041）
    介绍​栏 能力​:​沐浴​鲜血​(​生命​吸血​+​30%​) 能力​:​沐浴​鲜血​(​基于​实际​造成​伤害​的​30%​吸血​)
    实现 原生 AIav 吸血（实际无效） 脚本 HF22LS_Heal(src, dmg*0.30)

    越战越勇（Y042 11 级真面板 + B100 层数 buff）等 v1.05 的其它内容保持不变；本次脚本只新增这一行回血，并删掉了 Y03A 的冲刺条件/动作（HFX5_ 函数 12 → 10）。
