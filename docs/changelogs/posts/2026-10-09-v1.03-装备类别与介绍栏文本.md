# v1.03：装备类别修正、掉落层修正、介绍栏文本同步

本页记录第三批**已实现、待实机验证**的改动。母图仍是 `v1.0 正式版`
（SHA256 `62A1122ACEDA220B746DF730B1625C2AF8E3C149048E26FDC2AF5C37BDA6BD6D`），**没有被改动**；
下面这些内容已经写进测试图 `Maps\SAO_TEST\v1.03.w3x`
（SHA256 `3A144F7EE51FB6431CDDF8E1A93197776429C94D6DCE8369EE4AABC38221E7DD`），实机确认后才会进入正式版。

## ① issue #2 十件新装备的**装备类别**修正

上一批（v1.01 / v1.02）这十件的类别都留在了默认值「主武器」，游戏里就被装备系统当成主武器
（比如王女之冠本该占**头部道具**槽）。本版按母图 `war3map.j` 里装备槽的判定改回正确类别
（装备系统读的字段是 `icla`）：

| 装备 | 错误类别（v1.02） | 本版类别 | 母图槽位依据（`war3map.j`） |
| --- | --- | --- | --- |
| `I0Q9` 王女之冠 | 主武器 | **头部道具** | `qp4` = `ITEM_TYPE_PURCHASABLE` |
| `I100` 国王之冠 | 主武器 | **头部道具** | 同上 |
| `I0QB` 梦幻 | 主武器 | **副武器** | `qf4` = `ITEM_TYPE_CHARGED` |
| `I0OK` 君临天下 | 主武器 | **副武器** | 同上 |
| `I0QA` 玲珑仙裙 | 主武器 | **装甲** | `qm4` = `ITEM_TYPE_POWERUP` |
| `I0Q7` 爱意暖暖连衣裙 | 主武器 | **装甲** | 同上 |
| `I102` 雷暴战甲 | 主武器 | **装甲** | 同上 |
| `I0Q8` 禁忌之戒 | 主武器 | **装备道具** | `qs4` = `ITEM_TYPE_CAMPAIGN` |
| `I0OT` 风花雪月 | 主武器 | **装备道具** | 同上 |
| `I101` 划破天空 | 武器（本来就对） | **武器** | `qi4` = `ITEM_TYPE_ARTIFACT` |

> 其余类别（项链 / 手套 / 戒指 / 鞋子 / 灵魂装备）也都在「装备道具」这一档里，与母图 2.43 / 2.61 版本一致。

## ② `I101` 划破天空：掉落层 44 → 40

40 层 BOSS 是 `nfrs`，它的死亡掉落函数是 `f84`（原本 3 件掉落）。本版在这个函数里追加了一个
必定掉落块（`RandomDistAddItem('I101','d')`），44 层不再掉落它。

> v1.01 的说明页写的是「44 层 BOSS 必定掉落」，以本页为准（已修正）。

## ③ issue #3 的 16 件装备：**介绍栏文本**跟着数值一起改

v1.01 / v1.02 只改了对象数值（`war3map.w3a`），游戏里装备介绍栏显示的还是旧数字。
本版把这 16 件的 `Tip` / `Ubertip`（`war3map.w3t` 的 `ides` / `utub`）按新数值逐条重写——
颜色码、换行、其余文案原样保留，只动数字所在的那几行。

逐件的新旧文本见交付文档 `releases/v1.03/v1.03_变更单.csv`。

## ④ `I0IR` 灵魂宝具(花姬扇) 调整

| 项目 | 现值 | 本版值 | 说明 |
| --- | --- | --- | --- |
| 生命值 | +10000 | **+12000** | 新建技能副本 `Y030`（源技能 `A0TE` 保持原样） |
| 攻击力 | 无（本来不带攻击加成） | **+10000** | 新建技能副本 `Y031`（源技能 `A00P` 本来是「增加攻击50」） |
| 全属性加成 | 筋力 / 敏捷 / 体力 各 +100 | **删除** | 技能列表里去掉 `A0EF` |
| 湮灭之心（破甲光环 50） | 有 | 保留 | `A0UR` 不动 |
| 介绍栏文本 | 筋力:100 / 敏捷:100 / 体力:100 | **生命值:12000 / 攻击力:10000** | 已同步 |

> 花姬扇原先与别的装备**共用技能对象**——直接改数值会连带影响其它装备，所以本版走
> 「复制一份专属技能副本再改」的路线（过程表见 `patch_plan/data/ability_clones.csv`）。
