v1.04 把 issue #2 新增的十件装备**真正做了出来**：此前只迁移了面板数值，游戏里「沐浴鲜血」「越战越勇」「瞬间加速」等主动/被动效果一个都没生效。本版补齐效果（数据层 13 个原生克隆技能 + 脚本层 JASS 模块 HFX5），并给「七皇の统治者」加攻击力 +10000、魔法值 +100000，另按 m07405 把花姬扇归到道具类别。

<!-- more -->

## 一、根因（为什么之前没效果）

| 事实 | 证据 |
|---|---|
| 十件装备是全新对象 | 物品 `I0Q9…I0OT`、技能 `Y012…Y02F` 都是本版新建，母图里不存在 |
| 母图脚本完全没引用它们 | `war3map.j` 对这 10 个物品码、30 个技能码**引用 0 次** |
| 原版效果技能拿不到 | 2.61 图里 `war3map.w3a` 读不出，提取工程里 2.61 系 `war3map.w3a` 全是 12 字节空壳 |
| 母图没有现成效果调色板 | 全图没有「吸血 / 叠攻 / 冲刺 / 反伤 / 免疫」的脚本；但**有**伤害派发总线（`wY`/`tY`）可以注册自己的处理器 |

结论：面板数值能用原生克隆做，触发类效果必须自己写。

## 三、脚本层：JASS 模块 HFX5

母图没有原生基底的触发类效果，用本版新增的 JASS 模块实现（12 个函数，`pjass` 静态检查零错误）：

| 装备 | 效果 | 实现 |
|---|---|---|
| 王女之冠 | 沐浴鲜血 +30% | 伤害事件里 `SetWidgetLife(攻击者, +伤害×0.3)` |
| 王女之冠 | 越战越勇（每击 +1000 攻，上限 1 万，5 秒不攻击归零） | 哈希表按单位累计 + 5 秒定时器清零，追加伤害 |
| 划破天空 | 强行夺取 | 攻击回 500+全属性，并对目标追加 1000+敏捷×20 |
| 梦幻 | 噬魂 | 附带自身最大生命 5% 伤害，回复其中一半 |
| 君临天下 | 征战 | 造成伤害 +15%（追加伤害实现） |
| 玲珑仙裙 / 爱意暖暖 / 雷暴战甲 | 负面免疫（含恒温、雷神之体） | 每秒清 23 个负面 buff 码 |
| 爱意暖暖 | 爱意暖暖 | 自身受伤 → 700 范围友军等量回血 |
| 爱意暖暖 / 雷暴战甲 | 力量反射 筋力×3 / 镜面反射 敏捷×3 | 受击方反弹（走重入闸防递归） |
| 禁忌之戒 | 禁忌：每 1 点全属性 +10 攻击伤害 | 追加伤害 |
| 禁忌之戒 | 瞬间加速 | 主动技 `Y03A` → 复用母图 `dI4` 位移 400 |

伤害事件走母图自带的派发总线（`TriggerAddCondition` + `call wY(t)` + `TriggerAddAction`），初始化钩子插在母图触发器注册链 `P2MI_Register_014` 之后。

## 四、七皇の统治者：攻击力 +10000、魔法值 +100000

| 项 | 内容 |
|---|---|
| 技能列表 | `A0SA,A0PH,A0TE,Q15A,Q23R,Q23D` → 追加 `Y03F,Y040`（母图原有 6 个技能**保留**） |
| `Y03F` | ← 母图 `A00P`（基底 `AItn`）：`Iatt` 50 → **10000**，`anam`「增加攻击力10000」 |
| `Y040` | ← 母图 `X018`（基底 `AI2m`，全图唯一）：`Iman` 20000 → **100000**，`anam`「增加最大魔法值100000」 |

该物品没有 `ides` 文本字段——介绍栏里显示的那些行本来就来自各技能的 `anam`，所以上面两条新 `anam` **会自动出现在游戏内介绍栏**。

## 五、花姬扇改为道具类别（m07405）

`I0IR` 的 `icla` = **Campaign（道具）**。该物品原本没有 `icla` 字段，本版新建；顺带修掉了补丁工具把 `icla`/`icid` 当整数解析的类型表 bug（就是它让花姬扇那一路报 `could not convert string to float: 'Campaign'`）。

## 六、本版仍包含 v1.03 的改动

- 十件装备类别按母图槽位语义落定（头部道具=可购买、主武器=神器、副武器=充能、装甲=能量提升、道具=战役）
- 划破天空 `I101` 掉落层 44 → **40**（40 层 BOSS `nfrs` 的掉落函数 `f84` 追加）
- issue #3 十六件装备介绍栏文本（`ides`/`utub`）同步
- 花姬扇：生命值 +12000（`Y030`）、攻击力 +10000（`Y031`）、去掉全属性 +100（`A0EF`）；破甲光环 `A0UR.Had1` 本就是 -200，只对齐了文字

## 七、验证与已知近似

- 五层静态验证（对象层字段回读、文本层标题三处、脚本层 `pjass`、成员层差异、母图指纹）全部通过；**未经游戏内实测**。
- 脚本类效果是「近似实现」：越战越勇 / 征战 +15% / 强行夺取 / 噬魂 / 禁忌 都是**追加伤害**，不改真实攻击面板。
- 负面免疫是 23 个负面 buff 码的清单式清除；不屈意志借 `AOre`（永不眠类）基底，与 2.61 原技能不完全等价。
- 母图的吸血光环基底 `AUav` 不在母图对象里，所以沐浴鲜血只能用脚本实现。
