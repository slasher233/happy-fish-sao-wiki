# Wiki 措辞清理与「对象字段对照表」

本次**没有修改地图**。改动都在 Wiki 生成器（`wiki/scripts/build_items.py`、`build_heroes.py`、`build_site.py`、`wiki_common.py`）与页面文案上，对应审计清单里的 W005 / W011 / W029 / W030。

## 术语与措辞

- **`j 行号` → `触发器行号（war3map.j）`**：10 张触发类表格的列头（商店出售 / 从商店移除 / 抽奖 / 打造 / 掉落 / 另一形态 / 事件生成 / 触发时赠予 / 拾取使用 / 作为材料被消耗），共 532 行、312 个物品页。原来只写 `j`，读者不知道指哪个文件。
- **没有自定义名称的物品**：物品总览页由「显示为「原版名（原版）」」改成「显示为「未设置名称（原型 …）」」，与物品页标题（`# tpow · 未设置名称（原型 知识之书）`）统一说法。
- **名称里的 `*` 转义**：英雄名 `公会:命运之夜(four*king)` 在页内标题与图鉴表里会被 Markdown 当成斜体标记，现统一转义为 `four\*king`（只影响显示，**文件名与 URL 不变**）。

## 新增「对象字段对照表」

[对象字段对照表](../../info/对象字段对照表.md)（在「资料与说明」目录下）把本站正文里出现的内部字段集中成可检索的表：

- **表 1 物品字段（`war3map.w3t`）**：39 个字段 id 的中文名、所属分组、出现物品页数（现算）。
- **表 2 技能数值字段（`war3map.w3a`）**：物品绑定技能里实际用到的 137 个 `Data` 字段——改技能数值时真正要写的字段名。

物品页折叠块「全部对象字段（原始值）」的说明句现在指向本页（写盘时按页深自动改写成相对链接，不会出现项目站的根相对链接）。
