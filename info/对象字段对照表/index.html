    对象​字​段​对照表¶

    本页​把​本站​正文​里​出现​的字​段（如 ides、utub、iabi、Ilif）集中成一张可检索的对照表：它们是地图对象数据里的原始​字段名​（​WC3​内部​id​）。改了图以后要按这些 id 去找数据（写回 war3map.w3t / war3map.w3a / war3map.w3u）；游戏内与编辑器里显示的中文名只是客户端​本地化标签，不能用来检索对象数据。下表的中文名取自这份本地化字典（note_log/index/field_dict_units.tsv / field_dict_abilities.tsv，源头是客户端 War3Patch.mpq 的 UnitMetaData.slk / AbilityMetaData.slk 与 WorldEditStrings.txt）；字典里没有的字段写「（客户端未收录，见下方说明）」，本站不臆造译名。

    正文​里​的​「​字​段​」​指​什么¶

    本站​正文​里​出现字​段一词​时​，​一律​指​地图​对象​数据​的原始​字段名​（​WC3​内部​id​），例如 ides、Ilif；它既不等于游戏内显示的属性名，也不等于需求单 CSV 的列名。玩家​要​改​数值​请​看​各页​的​「​可改​数值​项​」​小节——那里列的才是可以直接改的项，改动落在私有需求单仓库 patch_plan/data/*.csv 的 new_value 列，不要直接改 Markdown；站点符号与用语口径见 术语​与​用语，​数据​来源​与​验证​分层​见地图​身份。

    数据​来源：刀剑物语 happy丶FISH v1.0 正式版（母图 SHA256 62A1122ACEDA220B746DF730B1625C2AF8E3C149048E26FDC2AF5C37BDA6BD6D）

    本页数值由该图的 war3map.w3u / war3map.w3a / war3map.w3t 与 war3map.j 解析生成；未​经过​实机​验证—​—​「​数据​来自​哪个​成员​」​不​等于​「​游戏​里​就是​这个​表现​」​。​哪些​内容​已​被​交叉​验证​、​有​哪些​已知​限制​，​见地图​身份；本页符号（— / 未判定（证据不足） / ⚠️ 不可选）的含义见 术语​与​用语。

    物品字段来自 war3map.w3t（SHA256 98164862404eee98a28c5b5ba01f88fceb7fca896b3b06457f1853d75bac896d）；技能数值字段来自 war3map.w3a（SHA256 80675c0549e25604b5b97bb05cd7f6594f92dfec95639cbdf6a6480ba2ffa9d3）；字段中文名、类型与取值范围来自客户端 War3Patch.mpq 的 UnitMetaData.slk / AbilityMetaData.slk 与 WorldEditStrings.txt。
